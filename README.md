# Optimal Poly Multiplication Selector for PQC Schemes

Finds the best PQC polynomial-multiplication algorithm for the ring  NTRU-HPS-2048-509 subject to RISC-V hardware and memory constraints.

Current Algorithms that will be benchmarked:

1) Karatsuba (https://en.wikipedia.org/wiki/Karatsuba_algorithm)
2) Toom-Cook (https://eprint.iacr.org/2023/678)
3) NTT (https://eprint.iacr.org/2024/585.pdf)
4) TVMP (https://open.metu.edu.tr/handle/11511/98549)
